# QR Code Generator

A simple, fast, and modern React application to create QR codes instantly from your text or links.

[**Live Demo ➔**](https://rahulshahare.github.io/qrcode-gen/)

---

## ✨ Features

- **Instant QR code generation**: Enter any text or URL, and see your QR code update in real-time.
- **Download as SVG/PNG**: Save your QR code image for easy use on print or digital media (if the feature is supported).
- **Responsive design**: Works great on both desktop and mobile.
- **Lightweight & Fast**: Minimal dependencies for a snappy experience.

---

## 🚀 Quick Start

Run these commands to get started locally:




```git clone```
 ```https://github.com/rahulshahare/qrcode-gen.git```

```cd qrcode-gen```

```npm install```

```npm start```
