# QR Code Generator

A simple React app to quickly generate QR codes from text or URLs.

[Live Demo ➔](https://rahulshahare.github.io/qrcode-gen/)

## Features

- Instant QR code generation as you type
- Download QR code as an image (if available)
- Clean, responsive design

## Quick Start


```git clone```
 ```https://github.com/rahulshahare/qrcode-gen.git```

```cd qrcode-gen```

```npm install```

```npm start```
